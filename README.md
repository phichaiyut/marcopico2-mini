# Robot Hotkey Macro (ฉบับปรับปรุง)

กดคีย์ลัดแล้วโปรแกรมจะพิมพ์โค้ดหุ่นยนต์ลง IDE (Arduino IDE / VS Code / Thonny) ที่บรรทัดปัจจุบันและขึ้นบรรทัดใหม่ให้เอง
ค่า `speed / cm / ms / dir / angle / action` ดึงมาจากหน้าต่างโพยที่ลอยอยู่บนสุดของจอ จึงเปลี่ยนค่าได้ตลอดโดยไม่ต้องแก้โค้ด

## ⏱ วันแข่ง: อ่าน 1 นาทีจบ

1. ดับเบิลคลิก **`run_macro.bat`** แล้วกด **Yes** ที่หน้าต่าง UAC (สคริปต์จะติดตั้งไลบรารีให้เองตอนรันครั้งแรก)
2. คลิกในหน้าต่าง IDE ตรงบรรทัดว่างที่จะเขียนโค้ด
3. ตั้งค่าในหน้าต่างโพย เช่น speed 70 / action `'p'` แล้วกดคีย์ลัด เช่น **Ctrl+Alt+1** จะได้ `ff(70, 'p');` และเคอร์เซอร์ลงไปบรรทัดใหม่ทันที
4. จะคลิกปุ่มในหน้าต่างโพยแทนก็ได้ โปรแกรมจะสลับกลับไปพิมพ์ใน IDE ที่ใช้ล่าสุดให้เอง (ดูชื่อหน้าต่างที่ "เป้าหมาย:")
5. ปิดโปรแกรมด้วย **Ctrl+Shift+Q**

### สูตรจำคีย์ลัด

| กลุ่ม | คีย์ | จำว่า |
|---|---|---|
| เดินตามเส้น | `Ctrl+Alt+1..4` = `ff ffc ffl ffr` | เติม **Shift** = ถอยหลัง (`bb...`) |
| ระยะ/เวลา | `Ctrl+Alt+5` = `ffcm`, `6` = `fft`, `7` = `fft` + action | เติม **Shift** = ถอยหลัง |
| Gyro วิ่ง | `G` = `ffcmg`, `H` = `ffcmgs`, `B` = `ffbg` | เติม **Shift** = ถอยหลัง |
| หันทิศสัมบูรณ์ | `N` = spindir, `M` = turndir, `Shift+M` = turndirb | ใช้ค่า dir |
| หมุน/เลี้ยวสัมพัทธ์ | `A`/`D` = หมุนซ้าย/ขวา, `Q`/`E` = เลี้ยวซ้าย/ขวา | เติม **Shift** ที่ Q/E = เลี้ยวถอยหลัง |
| แขนกล | `Ctrl+Alt+F1..F12` | ท่าผสมใช้ `Ctrl+Alt+Shift+F1..F8` |
| **รีเซ็ตมุมไจโร** | **`Ctrl+Alt+O`** = `resetAngles();` | O หน้าตาเหมือนเลข 0 (รีเซ็ตมุมเป็น 0°) · มีปุ่มสีเขียวเข้มบนแถบบนสุดด้วย |
| หมุนหาเส้น (เซนเซอร์หน้า) | `Shift+A`/`Shift+D` = `spinl`/`spinr` · `Shift+J`/`Shift+L` = `spinl2`/`spinr2` | J/L = ซ้าย/ขวา ข้ามไปเส้นที่ 2 |
| โค้งตามระยะ | `T`/`Y` = `ffcmcl`/`ffcmcr` | เติม **Shift** = ถอยหลัง (`bbcmcl`/`bbcmcr`) |
| โค้งถึงทิศ dir (จบโหมดเส้น) | `;`/`'` = `ffdircl`/`ffdircr` | เติม **Shift** = ถอยหลัง |
| โค้งถึงทิศ dir (จบ `*g`) | `Z`/`X` = `ffdirclg`/`ffdircrg` | เติม **Shift** = ถอยหลัง · เลือก None จะใช้ `'p'` แทนให้เอง |
| ตั้ง dir | `I` `L` `K` `J` = 0 / 90 / 180 / 270 | วางเป็นลูกศร: I บน, L ขวา, K ล่าง, J ซ้าย |
| ตั้ง action | `P` `C` `S` = 'p' 'c' 's'  ·  `,` = 'l'  ·  `.` = 'r' | `,` คือ `<` (ซ้าย), `.` คือ `>` (ขวา) · `/` วนตัวถัดไป · `U` สลับตัวเล็ก/ใหญ่ |
| ความเร็ว | `=`/`-` = ±5 · `8`/`9`/`0` = SLOW/DEFAULT/FAST | |
| ระยะ / เวลา | `]`/`[` = cm ±5 · `Shift+]`/`Shift+[` = ms ±100 | |
| อื่น ๆ | `R` = พิมพ์คำสั่งล่าสุดซ้ำ · `Shift+P` = หยุดชั่วคราว · `Shift+W` = ซ่อนหน้าต่าง | |

> คีย์ลัดทุกตัวในตารางนี้ต้องกด **Ctrl+Alt** ด้วย ยกเว้นปิดโปรแกรมที่ใช้ `Ctrl+Shift+Q`
> ใช้ได้ทั้งตอนแป้นพิมพ์เป็นภาษาไทยและอังกฤษ

### ตัวเลือกในหน้าต่างโพย

- **กด End ก่อน**: เลื่อนไปท้ายบรรทัดก่อนพิมพ์ (ค่าเริ่มต้น: เปิด)
- **Enter หลัง**: ขึ้นบรรทัดใหม่หลังพิมพ์ โดย IDE จะจัดย่อหน้าให้ (ค่าเริ่มต้น: เปิด)
- **ใส่ speed (opt.)**: กำหนดว่าคำสั่งที่ speed เป็น optional จะใส่ speed หรือไม่ ได้แก่ `spinl spinr spinl2 spinr2` และ `spindir/sdg spinlg/slg spinrg/srg` เช่น ติ๊ก = `spinl(70);` ไม่ติ๊ก = `spinl();` (ค่าเริ่มต้น: ติ๊ก)
- **ช่อง tol** (อยู่ขวาของแผงค่า): ปุ่ม `ไม่ใส่` `1` `2` `3` `5` หรือพิมพ์ตัวเลขเอง ใช้กับชุด `*dircl/*dircr/*dirclg/*dircrg` เท่านั้น ใต้ปุ่มจะแสดง `= None` เมื่อไม่ใส่
- **ลำดับพารามิเตอร์ของชุดโค้งถึงทิศ** (โปรแกรมเรียงให้ถูกเอง ดูได้ที่บรรทัด "ตัวอย่าง →")

  | Action | tol | `ffdircl` | `ffdirclg` (บังคับมี action) |
  |---|---|---|---|
  | None | ไม่ใส่ | `ffdircl(70, 90);` | `ffdirclg(70, 'p', 90);` |
  | `'p'` | ไม่ใส่ | `ffdircl(70, 'p', 90);` | `ffdirclg(70, 'p', 90);` |
  | None | 2 | `ffdircl(70, 90, 2);` | `ffdirclg(70, 'p', 90, 2);` |
  | `'p'` | 2 | `ffdircl(70, 'p', 90, 2);` | `ffdirclg(70, 'p', 90, 2);` |

  ชุดโค้งตามระยะ: None → `ffcmcl(70, 25);` · `'p'` → `ffcmcl(70, 25, 'p');`
- **ชื่อย่อ**: ใช้ชื่อสั้น `sdg tdg tdbg slg srg tlg trg tlbg trbg` แทนชื่อเต็ม
- **Gyro ใส่ act / Gyro ใส่ dir**: กำหนดว่าจะใส่พารามิเตอร์ optional ของ `ffcmg bbcmg ffcmgs bbcmgs` หรือไม่
  ถ้าติ๊กใส่ dir โปรแกรมจะใส่ `'p'` ให้ด้วยเสมอ เพราะพารามิเตอร์เป็นแบบเรียงตำแหน่ง เช่น `ffcmg(70, 20, 'p', 90);`
- **ย่อ**: ซ่อนแท็บปุ่ม ให้เหลือแค่ช่องค่ากับสถานะ
- **Action Pad**: มีปุ่มใหญ่ครบ 22 ตัวอักษร (ตัวเล็ก/ใหญ่แยกปุ่ม) พร้อมปุ่ม **None** คลิกครั้งเดียวก็เลือกได้ ปุ่มที่เลือกอยู่จะเป็นพื้นสีเข้ม ใต้แผงจะบอกความหมายของตัวที่เลือกทั้งโหมดเดินตามเส้น (ff/bb) และโหมด Gyro ส่วนบรรทัด "ตัวอย่าง →" จะเปลี่ยนตามทันที
  - สีปุ่มตามกลุ่ม: 🟥 หยุด `s S c C` · 🟩 ผ่าน/ทะลุ `p P b B` · 🟦 หมุนแยก `l L r R` · 🟧 เลี้ยวโค้ง `q Q e E` · 🟪 หลัง/Gyro `a A d D g G`
  - **None** = ไม่ใส่ตัวอักษร ใช้ได้กับ `ffcmg bbcmg ffcmgs bbcmgs` เช่น `ffcmg(70, 20);` ถ้าใช้กับคำสั่งที่ต้องมี action (เช่น `ff`, `bb`, `ffbg`) โปรแกรมจะไม่พิมพ์ และขึ้นเตือนสีแดงแทน
- เอาเมาส์ชี้ปุ่มคำสั่งจะเห็นตัวอย่างโค้ดที่จะถูกพิมพ์ก่อนกด

## ปรับแต่ง (`macro.py`)

ค่าที่ตั้งไว้ทั้งหมดอยู่บนสุดของไฟล์:

```python
DEFAULT_SPEED = 70
FAST_SPEED = 90
SLOW_SPEED = 40
DEFAULT_CM = 20
DEFAULT_MS = 500
DEFAULT_DIR = 0
DEFAULT_ANGLE = 90
DEFAULT_ACTION = 'p'
PRESS_END_BEFORE = True
PRESS_ENTER_AFTER = True
USE_SHORT_ALIAS = False
```

- **เพิ่มหรือแก้คำสั่ง**: แก้ในตาราง `MACROS` ตัวอย่างเช่น
  - `Cmd(CAT_LINE, 'ctrl+alt+1', 'ff', 'speed act')` คือ ชื่อฟังก์ชันตามด้วยรายการพารามิเตอร์
    เครื่องหมายท้ายชื่อ: `?` = optional ตามติ๊ก/ช่อง tol · `act~` = ตัดทิ้งเมื่อเลือก None (ตัดกลางรายการได้) · `act!` = บังคับมี ถ้า None ใช้ `'p'`
  - `Cmd(CAT_CUSTOM, 'ctrl+alt+shift+8', 'delay(ms)', raw='delay({ms});')` คือ ข้อความแม่แบบที่ใช้ `{speed} {cm} {ms} {dir} {angle} {act} {fast} {slow}` ได้
- **ตรวจหลังแก้**: รัน `run_macro.bat check` หรือ `python macro.py --selftest` จะเช็กว่าคีย์ลัดไม่ซ้ำและคำสั่งครบทุกตัว
- **พิมพ์ช้า/ตกหล่น** (เครื่องช้า): เพิ่มค่า `FOCUS_DELAY` และ `PASTE_SETTLE`

## แก้ปัญหา

| อาการ | วิธีแก้ |
|---|---|
| กดคีย์ลัดแล้วไม่มีอะไรเกิดขึ้น และ IDE เปิดแบบ Administrator | เปิดโปรแกรมนี้ผ่าน `run_macro.bat` แล้วกด Yes ที่ UAC (Windows ไม่ยอมให้โปรแกรมสิทธิ์ต่ำกว่าส่งปุ่มเข้าหน้าต่าง admin) |
| สถานะขึ้นว่า "คีย์ลัดที่ใช้ไม่ได้ (โปรแกรมอื่นจองไว้)" | มีโปรแกรมอื่นจองคีย์นั้นไว้ เช่นแผงควบคุมการ์ดจอ Intel/AMD ที่ใช้ Ctrl+Alt+F-key ให้ปิดคีย์ลัดของโปรแกรมนั้น หรือเปลี่ยนคีย์ใน `MACROS` |
| ขึ้นว่า "ยังกด Ctrl/Alt/Shift ค้างอยู่" | ให้ปล่อยปุ่มทั้งหมดก่อน โปรแกรมจะรอให้ปล่อยแล้วค่อยพิมพ์ เพื่อไม่ให้กลายเป็นคีย์ลัดอื่นของ IDE |
| ขึ้นว่า "ยังไม่รู้ว่าจะพิมพ์ลงหน้าต่างไหน" | คลิกที่หน้าต่าง IDE 1 ครั้ง แล้วกดปุ่มหรือคีย์ลัดใหม่ |
| ข้อความใน Clipboard หายหลังพิมพ์ | โปรแกรมคืนค่าเฉพาะข้อความ ถ้าเคย copy รูปไว้ รูปนั้นจะหายไป |

## ปรับปรุงอะไรจากต้นฉบับ

| ต้นฉบับ | ฉบับนี้ |
|---|---|
| `keyboard.add_hotkey` + `keyboard.write` | คีย์ลัดใช้ Win32 `RegisterHotKey` ซึ่งกันไม่ให้คีย์ลัดหลุดไปถึง IDE ไม่ทำให้ปุ่มค้าง และอ้างอิงตำแหน่งปุ่มจึงใช้ได้ทั้งแป้นไทย/อังกฤษ |
| พิมพ์ทีละตัวอักษร ซึ่งเพี้ยนเมื่อแป้นเป็นภาษาไทย และ IDE เติม `)` `'` ซ้ำ | วางผ่าน Clipboard (Ctrl+V ส่งเป็น virtual-key) แล้วคืนค่า Clipboard เดิม |
| ค่าตายตัวในโค้ด | หน้าต่างโพยแบบ Always-on-Top ที่เปลี่ยนค่าได้ทันที มีพรีวิว และกดปุ่มเพื่อพิมพ์ได้ |
| คีย์ลัด Ctrl+Shift+1..6 | ระบบคีย์ลัดแบ่งหมวดตามหลักจำ รวม 94 ชุด และตรวจคีย์ซ้ำอัตโนมัติ |
| | กดปุ่มว่าง (VK 0xE8) คั่นทันทีที่คีย์ลัดทำงาน เพื่อไม่ให้ Alt เปิดเมนูของ IDE หรือ Alt+Shift สลับภาษา |

## ไฟล์

- `macro.py`: โปรแกรมหลัก (Python 3.8+ บน Windows ใช้ `tkinter` ที่มากับ Python)
- `run_macro.bat`: ตัวเปิดโปรแกรม เช็กสิทธิ์ admin หา Python ติดตั้ง `keyboard` + `pyperclip` รัน self-test แล้วเปิดโปรแกรม
  - `run_macro.bat noadmin`: เปิดโดยไม่ขอสิทธิ์ admin
  - `run_macro.bat check`: ติดตั้งและตรวจอย่างเดียว ไม่เปิดโปรแกรม
